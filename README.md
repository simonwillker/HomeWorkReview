# 作业检查与复习 App（HomeWorkReview）

根据《家庭作业检查与复习 App 设计书 v1.0》实现的 **MVP 1**：家庭账号、作业录入、提交、自查、检查、手动订正、家长确认与间隔复习的完整闭环。

核心闭环：记录作业 → 完成与上传 → 检查和订正 → 家长确认 → 按计划复习 → 再次检验。

## 运行

```bash
npm install
npm run dev        # 开发模式 http://localhost:5173
npm test           # 领域逻辑单元测试（Vitest）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
```

## 部署

推送到 `main` 后，GitHub Actions（`.github/workflows/deploy.yml`）会运行测试、构建并发布到 GitHub Pages：
https://simonwillker.github.io/HomeWorkReview/

工作流带 `enablement: true`，会自己创建 Pages 站点，**不需要手动去 Settings → Pages 设置 Source**。

但 **仓库必须是 public**：GitHub Pages 对 private 仓库要求 GitHub Pro 以上的付费计划，
否则这一步会以 `Get Pages site failed ... Not Found` 失败。

应用是手机优先的 PWA（iPhone / Android 浏览器“添加到主屏幕”即可像 App 一样使用，平板自适应）。数据保存在本机：业务数据在 localStorage，照片在 IndexedDB，离线可用。

## 日记检查（2026-09-27 追加）

把写好的日记拍照放进来，页面会分成四类提示，修改稿可以继续编辑并保存。

| 分类 | 看什么 |
| --- | --- |
| 🔤 常见错别字 | 「ぼくわ→ぼくは」「学校え→学校へ」「こんにちわ」「とゆう」「楽しいかった」「つずく→つづく」等 26 条规则。能一键替换的会给「なおす」按钮 |
| ✍️ 小学已学汉字的写法 | 用**学年別漢字配当表**（文部科学省「小学校学習指導要領（平成29年告示）」，1〜6 年共 1026 字）判断：这个字几年级学、有没有超出年级、哪些假名词已经可以写成汉字；形近字（犬/大、玉/王…）提醒对照照片确认 |
| 📏 文法与标点 | 句末的「。」、误用的「，．」、引号成对、一句太长、敬体与常体混用、「〜たり」单用、句首的「なので」、分段 |
| 💡 内容表达 | 先夸「写得好的地方」（对话、心情、五感、具体数字），再提「何时・何地・和谁」「为什么这么想」「同一个词重复」「结尾只写了『楽しかった』」 |

提示分四档：**なおそう（要改）/ たしかめよう（请确认）/ くふうしよう（可以更好）/ できているね（做得好）**。
每一条都用小学生能读懂的日语写（日记是日语，改的人要看得懂），下面附一行中文给家长。
一个分类最多显示 6 条要改的，但「做得好」全部显示——不让它变成纯粹的挑错。

年级在「我的 → 家庭成员」里选，只影响「这个汉字学过了吗」的判断（默认 6 年级，最宽松）。

### 为什么文字要自己输入一次

App 不联网、数据只留在本机，**离线的浏览器里做不准手写识别**。认错的字会被当成错别字教给孩子，
所以宁可让人抄一次：iPhone / iPad 用「实况文本」（长按照片上的文字 → 全选 → 拷贝）一步就能拿到文字，
安卓用 Google 相册或「镜头」。照片作为凭据一起保存，原稿（text）和修改稿（revised）分开存，方便前后对照。

检查逻辑全部是纯函数，放在 `src/domain/diary/`（`typos.ts` / `kanji.ts` / `grammar.ts` / `content.ts`），
有 37 个单元测试，包括「配当表的字数与告示一致（80/160/200/202/193/191）」这类数据校验。
如果以后接入服务端或云端 OCR，只要把「照片 → 文字」那一步换掉，检查逻辑不用动。

## 目录

```
src/domain/   领域逻辑（纯 TypeScript，无 UI 依赖，可直接迁移到服务端）
  diary/          日记检查：kanjiGrades.ts（学年別漢字配当表 1026 字）/ typos.ts /
                  kanji.ts / grammar.ts / content.ts / index.ts（checkDiary・applyFix）
  types.ts        数据结构
  status.ts       作业状态机
  revision.ts     复习间隔
  answers.ts      答案规范化与比对
  clarity.ts      照片清晰度检测
  permissions.ts  角色权限
  service.ts      业务服务：权限校验 + 状态流转 + 操作记录
src/data/     本地存储（localStorage / IndexedDB）
src/ui/       React 页面与组件
tests/        单元测试
```
