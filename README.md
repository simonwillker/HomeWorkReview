# 作业检查与复习 App（HomeWorkReview）

根据《家庭作业检查与复习 App 设计书 v1.0》实现的 **MVP 1**：家庭账号、作业录入、提交、自查、检查、手动订正、家长确认与间隔复习的完整闭环。

核心闭环：记录作业 → 完成与上传 → 检查和订正 → 家长确认 → 按计划复习 → 再次检验。

## 运行

```bash
npm install
npm run dev        # 开发模式 http://localhost:5173
npm test           # 领域逻辑单元测试（Vitest）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
```

## 部署

推送到 `main` 后，GitHub Actions（`.github/workflows/deploy.yml`）会运行测试、构建并发布到 GitHub Pages：
https://simonwillker.github.io/HomeWorkReview/

首次使用前需在仓库 Settings → Pages → Build and deployment 中把 Source 设为 **GitHub Actions**。

应用是手机优先的 PWA（iPhone / Android 浏览器“添加到主屏幕”即可像 App 一样使用，平板自适应）。数据保存在本机：业务数据在 localStorage，照片在 IndexedDB，离线可用。

## 已实现（对应设计书）

| 设计书 | 实现 |
| --- | --- |
| 2 角色与权限 | 学生 / 家长；一个家长管理多个孩子。切换到家长身份需要 PIN，学生无法使用确认操作；权限统一在服务层 `src/domain/permissions.ts` 校验 |
| 3.1 每日作业 | 科目、标题（必填）、截止日期、预计用时、要求、通知照片；可选录入参考答案与来源 |
| 3.1 自查与答案比对 | 四项自查清单；**只有录入了参考答案才做答案比对**，否则显示“待人工检查”，不猜测答案 |
| 3.1 订正与确认 | 错题/存疑题记录订正与原因；家长查看原图、完成项、订正后“确认”或“退回修改”（退回必须填写原因） |
| 3.2 复习 | 订正自动生成复习卡片，也可手动收藏知识点；默认次日、3 天后、7 天后；先作答后看参考；“还不熟”次日再练；家长可修改间隔、调整日期、关闭提醒 |
| 状态规则 | `src/domain/status.ts` 状态机：待开始 → 进行中 → 待检查 → 待订正（可选）→ 待家长确认 → 已确认；退回 → 待修改 → 待检查；已确认后有新订正 → 新版本并重新请求确认，保留原确认记录；逾期只是标识 |
| 4 页面 | 今日、新增作业、作业详情、检查结果、家长确认、今日复习、学习记录、我的；底部导航“今日｜复习｜记录｜我的”；状态均有文字，不单靠颜色 |
| 5 检查逻辑 | 照片清晰度检测（拉普拉斯方差），看不清提示重拍并支持补拍；每条比对结果可“查看依据”和“标记建议有误” |
| 6 数据结构 | `src/domain/types.ts`；照片只保存引用；修改、退回、确认写入操作记录 |
| 7 验收规则 | 无照片可完成但只能确认完成情况；未订正错误可确认“已查看”但不会显示为“全部正确”；复习卡片答题后才显示参考 |
| 8 隐私 | 一次性 6 位邀请码（24 小时有效，可作废）；导出孩子数据（含照片）、删除孩子数据并提示对其他成员的影响；不收集真实姓名、学校、位置、通讯录 |

## 目录

```
src/domain/   领域逻辑（纯 TypeScript，无 UI 依赖，可直接迁移到服务端）
  types.ts        数据结构
  status.ts       作业状态机
  revision.ts     复习间隔
  answers.ts      答案规范化与比对
  clarity.ts      照片清晰度检测
  permissions.ts  角色权限
  service.ts      业务服务：权限校验 + 状态流转 + 操作记录
src/data/     本地存储（localStorage / IndexedDB）
src/ui/       React 页面与组件
tests/        单元测试
```

## 尚未实现 / 后续

- **服务端与多设备同步**：目前数据只在单台设备上。家长 PIN 只防止同一设备上孩子切换身份，不是正式认证；接入服务端后，`HomeworkService` 中的权限与状态规则须在服务端执行，并实现离线冲突“保留两个版本并提示家长处理”。
- MVP 2：照片 OCR（识别结果须经确认才保存）、系统推送通知（当前仅在“今日”页内提醒，并遵守夜间免打扰）。
- 后续：作文建议、老师角色、日语界面（界面中已预留选项）。
- 设计书第 10 节的待确定事项（首发地区、答案提供方、照片保存期限等）仍需确认。
